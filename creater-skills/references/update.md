# 模板维护与更新

本项目已经提取并采用四目录结构，不再使用原完整课程仓库的整包覆盖更新流程。

需要更新基础设施时，先备份四个目录和根说明，停止本模板的服务，再明确需要迁入的公共组件、服务或工具。迁移时同步更新 environment/ 下的配置与相关文档，执行 creater-skills/check.ps1 和浏览器检查。

courses/ 中的课程、签名身份与公钥，以及 environment/backend/.private/ 私钥必须保持对应关系；不得通过更新重新初始化或重签。不要覆盖用户创作内容与 creater-skills/preferences/ 偏好记录。

模板重新分发前排除运行产物、依赖和私钥。参考根目录 README.md 中的数据位置说明。
