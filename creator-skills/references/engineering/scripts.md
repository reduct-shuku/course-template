# 工具脚本规范

模板工具位于 creator-skills/tools/，Python 创作包位于 tools/python/idl_authoring/，回归在 creator-skills/tests/。维护已有工具时沿用入口与参数，不复制来源仓库的工具分发器、计算后端或服务管理。

- 文件头说明用途、读取与写入范围、覆盖行为；参数提供帮助。
- 导入模块不解析参数、扫描项目、启动服务或联系远程系统；可选依赖在实际执行时加载。
- 把业务函数与命令行编排分开，返回真实结果及可定位的输出路径。错误明确退出，不能把帮助执行成功说成业务验收。
- 路径边界、已有文件保护、原稿只读和覆盖条件由代码验证，并添加针对行为的测试。
- 逐页设计、prompt 和检查截图写页目录的 _scratchpad/，整份原稿与汇总放模块级 _scratchpad/；正式素材单独归档。
- 凭证不进入命令示例、前端和课程包。上传、提交与发布沿用任务实际授权。
- 当前可用命令与环境见 [工具索引](../tools.md)，不能假定来源仓库的命令已移植。
